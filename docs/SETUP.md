# Local setup

Install Node.js 22 and pnpm 9.15.9, then run `pnpm install`, `pnpm typecheck`, `pnpm test`, `pnpm build`, and `pnpm dev`. Web: http://127.0.0.1:5173; API: http://127.0.0.1:3001/health. No Azure resources required. The `lint` script currently uses TypeScript checks; ESLint is not yet configured.
